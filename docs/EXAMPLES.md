# Example Reelpen prompts

Connect and allow a scene using the [setup guide](https://beta.reelpen.ai/guides/connect-your-ai). Read current capabilities and confirm the target before changing it. These are instructions for a connected assistant, not a claim that every client has been tested.

## Read before editing

> Read my allowed Reelpen scene without modifying it. Report its project name, whether it is live, the objects and the cameras. Explain any missing permission.

## Following shot

> Keep my existing objects. Add a Dolly with a short walking route and a following camera. Read current capabilities, apply one scene-edit batch and show a camera preview. Tell me what changed.

## Sit, wait, stand

> Inspect this character and nearby seat. Read the supported action-sequence settings. Set up sit, wait and stand with explicit seat height and facing. Preserve unrelated objects. Preview the full sequence and report any contact problem rather than claiming automatic chair attachment.

## Camera alternative

> Keep the existing camera. Add a second camera angle for this scene, give it an independent route and a look target on the character, and show its preview. Do not delete or replace the original shot.

## Street layout

> Read the road-extension capabilities. Extend the selected road from its end, preserving its existing layout. Use a connected right turn and explain the resulting placement.

## Export

> Read the available capture formats and current duration. Help me create a reference video and useful PNG frames. State any browser or connection limitation before recording.

## After a timeout

> Check the previous operation's status and read the scene before retrying. Do not blindly repeat a write that may already have succeeded.
